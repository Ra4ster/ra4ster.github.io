## 💻 Selected Work

Here is a selection of my recent projects spanning systems programming, machine learning, and algorithm optimization. Each is built around a concrete technical challenge and a measurable outcome.

### 1. SIMD-Optimized Levenshtein Distance

A highly optimized edit-distance implementation in C using AVX2 and POSIX, designed to significantly outperform naive approaches. Demonstrated measurable performance gains through vectorization and low-level optimization.

![SIMD Levenshtein Distance Output](/public/LevenshteinDistanceOutput.png)

- **Category:** Systems / Performance
- **Tools:** C, AVX2, SIMD, POSIX
- **GitHub:** [Optimized-Levenshtein-Distance](https://github.com/Ra4ster/Optimized-Levenshtein-Distance)

### 2. Moderation Classifier (BERT)

A multi-class moderation classifier built using BERT with PyTorch and ONNX, designed for real-time content classification. Built an end-to-end ML pipeline including training, optimization, and deployable inference.

![Automod Classifier](/public/automod.png)

- **Category:** Machine Learning
- **Tools:** Python, PyTorch, ONNX, Transformers
- **GitHub:** [Automod-Classifier](https://github.com/Ra4ster/Automod-Classifier)

### 3. Custom Desktop Environment

A taskbar and desktop implemented in Win32, focusing on webview, reverse engineering, and performance.

![Custom Desktop Environment](/public/glass_pill.png)

- **Category:** Systems / UX
- **Tools:** C++, Networking, Data Structures
- **GitHub:** [Railing](https://github.com/Balcony4Windows/Railing)

### 4. Deepity

A predictive coding library created in C++ with bindings for Python, delivering performance on CPU currently faster than top libraries like pcn-torch. Achieved 93% accuracy on MNIST in 1000 seconds.

![MNIST Results](/public/MNIST_results.png)

- **Category:** Machine Learning
- **Tools:** C++, BLAS, OpenMP, Python, CUDA, CMake
- **GitHub:** [deepity](https://github.com/Ra4ster/deepity)
